# JavaScript Calculator Lab

This project is a simple JavaScript calculator that performs addition, subtraction, multiplication, and division. It also stores each calculation in a history array and displays the full calculation history.

## Features

- Add two numbers
- Subtract two numbers
- Multiply two numbers
- Divide two numbers
- Prevent division by zero
- Store calculation history
- Display calculation history in the console

## How to Run

1. Open the project in Visual Studio Code.
2. Open the terminal.
3. Run the program with:

```bash
node labJavascriptCalculator.js
```

## Example Output

